# Getting Support

Thanks for using **SwarmAI — CEO Agent**. Here's how to get help.

## Before you ask

- Run the built-in diagnostics: `swarmai doctor`
- Check the gateway health: `swarmai status`
- Make sure you're on the latest release: `npm install -g @northpeak/swarmai`
- Tail the event bus while reproducing the issue: `swarmai logs --tail 100`

## Where to get help

| I want to… | Go to |
|------------|-------|
| Report a bug or request a feature | [GitHub Issues](https://github.com/northpeakmalaysia/SwarmAI/issues) |

## Filing a good issue

To help us help you fast, please include:

- **What you expected** vs. **what happened**
- **Steps to reproduce**
- **Your environment** — OS, Node version (`node -v`), SwarmAI version (`swarmai --version`)
- Relevant output from `swarmai doctor` and `swarmai logs` (redact secrets!)

> ⚠️ Never paste API keys, tokens, passphrases, or `.env` contents into a
> public issue.
